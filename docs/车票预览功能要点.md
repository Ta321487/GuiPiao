# 车票预览功能要点（TA_WPF）

## 1. 入口与使用方式

| 方式 | 说明 |
|------|------|
| **「全部车票」页工具栏** | `QueryAllTicketsPage` 中「预览车票」按钮，绑定 `PreviewTicketCommand`。 |
| **选中条数限制** | 仅当选中 **恰好 1 条** 车票时可用（`CanPreviewTicket`）；翻页、改页大小时会刷新该状态。 |
| **表格行右键** | 在车票 `DataGrid` 上右键：会先按规则选中该行，再 **直接执行** 与按钮相同的预览命令（等价快捷入口）。 |
| **窗口行为** | `TicketPreviewWindow` 以 **模态** `ShowDialog()` 打开，`Owner` 为当前主窗口。 |

核心调用：`QueryAllTicketsViewModel.PreviewSelectedTicket()` 内 `new TicketPreviewWindow(selectedTicket)`。

---

## 2. 界面结构

- **左侧（约 380px）**：滚动表单区「车票信息」——以 `TrainRideInfo` 为主数据源，**多数字段只读展示**；底部为 **可编辑** 的「身份信息」「编码区」及票种/支付相关选项。
- **右侧**：`Viewbox` 内固定 **811×509** 的 `PreviewGrid`，叠放底图与文字/图形，模拟实体票版式。

相关文件：`Views/TicketPreviewWindow.xaml`、`Views/TicketPreviewWindow.xaml.cs`、`ViewModels/TicketPreviewViewModel.cs`。

---

## 3. 左侧表单展示的数据字段（只读）

与票面一致的业务字段，主要包括：

- 车票号码、检票口  
- 出发/到达站、站名拼音  
- 出发日期、车次、出发时间（由 `DepartTime` 格式化为 `HH:mm`）  
- 车厢号、座位号、金额（表单里 `¥` + `N2` 展示）  
- 附加信息、座位类型  
- 车票改签类型、车票用途  
- **票种标志**、**支付渠道标志**（数值经 `TicketTypeFlagsConverter` / `PaymentChannelFlagsConverter` 转成可读文本）  
- **提示信息** `Hint`（票面虚线框内为多行，见第 5 节）

---

## 4. 身份信息与编码区（可编辑）

- **身份信息**（`IdentityInfo`）：支持输入 **18 位身份证**；完整 18 位时校验格式、出生日期段、加权校验位；不通过则弹窗提示、清空输入，并用 **红边框** 提示（短时状态）。  
- **编码区**（`EncodingArea`）：文本变更后调用 **QRCoder** 生成二维码（ECC 等级 Q，黑字、透明底），绑定到票面二维码图像。

---

## 5. 右侧仿真票面能力

- **红/蓝票**：底图 `Resources\Images\redTicket.png` / `blueTicket.png`；命令切换，两套 **独立 Thickness 布局表**（`InitializeTicketLayouts`），切换时批量刷新坐标相关属性。  
- **主题**：跟随 本项目的深色、浅色模式设定，调整 **窗口表单** 前景/背景/输入框色；票底图在深色下 **略降不透明度**。  
- **站名排版**：去掉「站」；按字数在字间插入不同 Unicode 空格，控制票面站名字距。  
- **车次与箭头**：根据出发/到达站名长度等，用多个 **Converter** 计算箭头、拼音偏移、「站」字位置等。  
- **金额在票面上**：`MoneyValue` 使用 **一位小数**（`N1`），与左侧表单 `N2` 展示可不一致，以票面逻辑为准。  
- **车厢/座位**：去掉车厢字符串中的「车」「加」；**加挂车**、**无座** 等有单独可见性与边距。  
- **卧铺**：当座位类型为「新空调硬卧/软卧」且座位号含上/中/下时，拆成 **数字铺位号** + **上铺/中铺/下铺** 文案及独立边距。  
- **提示**：`Hint` 按 `|` 拆成多行（`HintLines`）显示在票面提示区域。

---

## 6. 票种与支付渠道在票面上的表现

- 左侧 **复选框**（学生、优惠、网络售票、儿童）及各 **银行/三方支付** 显示开关，由 `TrainRideInfo.TicketTypeFlags`、`PaymentChannelFlags` **初始化**；存在有效 `SelectedTicket` 时选项 **锁定**（与数据库/模型一致，避免随意改标志语义）。  
- **业务规则**：若支付渠道中含 **支付宝或微信**，则 **不再** 根据标志单独显示「网络售票」网标（避免与在线支付重复语义）。  
- **可选展示**：「使用 **折** 替代 **惠**」；「**带框** / 不带框」显示票种与支付简字（蓝票用 **圆框** 样式，红票用 **方框** 样式）。  
- 票面简字示例：学、孩、网、惠/折；支、微；农、建、工、招、邮、中、交等。

---

## 7. 字体与窗口

- 窗口字体跟随资源 `MaterialDesignFontSize` 或 `app.config` 的 `FontSize`，并派生小号/大号/标题字号用于表单层级。  
- 最小尺寸约 **1000×650**，默认约 **1100×700**，屏幕居中。

---

## 8. 底部操作按钮

- **导出图片**：将 `PreviewGrid` 按 **811×509** 渲染到 `RenderTargetBitmap`，白底 + 内容，**PNG** 保存；默认文件名：`出发站(去「站」)-车次-到达站(去「站」)`；空文件名会提示。  
- **红/蓝切换**：切换 `IsRedTicket` 并刷新票种边框样式与边距。  
- **关闭**：触发 `RequestClose` 关闭窗口。

说明：`FullScreenWindowStyleConverter` / `FullScreenWindowStateConverter` 在本窗口 XAML 资源中声明，当前未绑定到具体控件。

---

## 9. 扩展能力（代码层）

- `TicketPreviewViewModel.UpdateLayout(Dictionary<string, object> layoutValues, bool isRedTicket)`：可按字典更新红/蓝某一侧的 **布局参数**，若与当前票面类型一致则立即刷新 UI（供外部或将来调版使用）。

---

## 10. 依赖与模型要点

- **二维码**：QRCoder。  
- **数据模型**：`TrainRideInfo`（含 `TicketTypeFlags`、`PaymentChannelFlags` 等）。  
- **设计时**：无参构造函数提供示例 `TrainRideInfo`，便于 Blend/设计器预览。

## 附录：与 GuiPiao 当前「测试预览」的对照（2026）

本文档仍以 **TA_WPF 目标形态** 为准；**GuiPiao** 里同名窗口目前只做 **效果与交互验证**，未逐项复刻上表能力。便于对照时记住差异即可：

| 文档要点 | GuiPiao 当前状态（简述） |
|----------|-------------------------|
| 入口（仅 1 条、Query 页等） | 主界面 **多选** 行程 +「票面预览」/双击等入口；与 TA 条数策略不同。 |
| 右侧 811×509 + Viewbox + 底图 | 当前为 **矢量票面** + 滑块调宽高/偏移/字号；**无**固定像素画板与 PNG 底图叠字。 |
| `TrainRideInfo` / 标志位 Converter | 列表侧为 **`TripItem`**；预览侧用 **`TicketPreviewDraft`** 包一层，**不写回**实体。 |
| 身份证校验、红框、QRCoder | **未做**；二维码为占位框。 |
| 站名字距、箭头 Converter、卧铺/加挂等 | **未做**；仅基础拆字（年/月/日、车、号、站、元等独立 `TextBlock`）。 |
| 导出 PNG、`UpdateLayout` 字典 | **未做**；后续可接 `RenderTargetBitmap` 与布局表。 |
| 主题 | 窗口跟 **ThemeManager** 的浅/深资源；票面用 **`TicketVoucher*`** 主题键，与文档「表单跟主题、底图降透明度」思路一致，细节未完全对齐 TA。 |

后续若要把测试预览升级为「生产级票面」，建议按本文 **第 2～9 节** 分阶段迁移，并保留 `TicketPreviewDraft` 与数据库实体的边界。
